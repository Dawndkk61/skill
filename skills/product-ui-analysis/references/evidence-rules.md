# 证据与测量

源记录包含 ID、原文件名、尺寸、哈希、页面、主题、已知状态。跨截图比较先核对窗口尺寸、账户 / 版本、滚动区域。占位文案、模型、耗时、焦点、展开层级、权限差异不自动归因于主题。

RGB 数字的意义依赖色彩配置。跨图比较应在副本上统一到 sRGB 并记录转换。`sample_png.py` 读取文件存储通道，不做 ICC 转换；非 sRGB / 未知配置不能声称已归一化。透明像素不能忽略 alpha，必须保留背景或记录合成方式。

| 类型 | 可以记录 | 不可外推 |
|---|---|---|
| observation | 可见位置、层级、图标、文案 | 点击结果、隐藏行为、控件树 |
| sample | 区域像素、坐标、方法、命中占比 | 原生 CSS / Figma 变量 |
| estimate | 参数、单位、误差、候选范围 | 精确源码值、已校准截图倍率 |
| config | 设置项明确显示的字体、字号、开关值 | 字体实际加载、所有组件继承 |
| inference | 建议角色、组件边界、Figma 变体 | 产品已采用该库 / 绑定 |
| unknown | 遮挡、未显示、未操作、无法标定 | 用常见设计规范补成事实 |

平坦填充从内部取小块，常用 9×9 众数，记录总像素、命中数和坐标；混色时移动或缩小，不宣称整块一致。文字抗锯齿、透明度和受限态影响观感。颜色比较不自动升级为合规评估。

圆角、边界、间距、阴影分开。细线未必是 border，也可能是 inset shadow 或背景分隔。按可见几何确定容差，不能机械给所有参数同一误差。裁切坐标 `[x,y,width,height]` 对应指定原图，缩略图标注按比例换算。

工作区标准经用户确认后启用。例如标准为 2560×1440 时，完整 5120×2880 图按 2× 换算，误差同步除以 2，原值与证据坐标保留。对其他来源，先确认标准与帧范围；映射不足时保留原图单位，不推断 DPR。全宽但高度不足的截图仅在明确确认后按统一倍率换算，不独立拉伸高度。配置直接显示的 13 px 不做倍率换算。标准 px 是报告分析单位，不能因此反推精确 CSS 字号/字重；字体未知时报告示例标明使用报告字体。

原始层按明确值与单位归组，语义层按用途建立候选别名，组件层保留具体参数来源。保留状态与例外，例如受限模板灰化不合入普通可用态。

Figma 变量 / 组件变体可作为设计建议，实际写入仅在用户要求时开始相应工作流。没有运行中 / 失败 / 成功证据时，不补成已观察状态。
