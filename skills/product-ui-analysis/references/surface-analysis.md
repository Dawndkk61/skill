# 工作台与 IDE 分类

先建立「产品 → 分类 → 页面与状态 → 主题 → 证据」的索引。用户指定的目录分类作为起点，产品名称匹配时同时核对已有报告的标题与样本。仅在同一产品已采集两个分类时提供双入口。

| 维度 | 工作台 | IDE |
| --- | --- | --- |
| 典型分析对象 | 会话或任务列表、计划、审批、执行状态、产物 | 活动栏、文件树、编辑区、差异视图、编辑器旁的 Agent、IDE 设置 |
| 独立记录 | 业务阶段、主题与组件 | 窗格布局、并行状态、主题与组件 |

- 各分类使用独立的 `analysis.json` 和 HTML。顶层 `product` 沿用产品名，`surface` 填 `工作台` 或 `IDE`，`conclusion` 写一到两句证据支持的分类结论。报告模板会在变量总览标题与短简介呈现这些信息。
- 同一产品的入口保留一个身份，用分类链接打开各自报告。现有入口有搜索、返回链接或资源下载时，核对增量更新后这些功能可用。仅在用户要求同步时发布线上更新。
- 变量、色值与几何仅绑定到同分类、同页面和同组件的样本。只有深色时仅记录深色值。内嵌浅色网页单独归为产物内容。IDE 截图里的工作台入口只证明该入口可见。
- 将真实空白、容器内缩、行列节奏和容器尺寸分别命名。跨产品间距对比使用真实边到边空白或内缩。布局宽度、中心距和列起点距保留在组件的几何记录里。
- 若用户另要色轮或色值表，按产品、分类、主题分别按 HEX 去重，保留原始用途对应关系。比较色轮沿用同一 OKLCH 尺度，并注明未采集的主题。
